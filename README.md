# VIM Webworks — Website

The public website for **VIM Webworks**, a brand-led website service for small businesses.

This is a **private repository** and the site is **not published** until the owner approves launch.

---

## What this is (plain English)

- A **static website** — just `index.html` (HTML, CSS, and a little JavaScript, all in one file).
- No server, no database, no build step. That makes it fast, cheap to host, and easy to move.
- Hosted for free on **GitHub Pages** to start, with a plan to move to **Hostinger** later.

## How to view it

- **Locally:** download `index.html` and double-click it — it opens in any web browser.
- **Live (once GitHub Pages is enabled):** a private-ish URL at `https://faustofortuna.github.io/<repo-name>/`.
- **Custom domain (later, after approval):** `vimwebworks.com` can be pointed here for free, including HTTPS.

## Design

Built to the approved **"Confident Human Studio"** direction:
- Palette: paper `#F4F0E6`, ink `#121411`, moss `#24352A`, citrus `#C9F04B`, clay `#D95F3F`.
- Type: Fraunces (display serif) + Inter (body sans), loaded from Google Fonts.
- Pricing: Launch Page `$995`, Business Site `$1,500`, Website Care `$150/month`.
- Primary action: **Request a Website Consultation** → `judah@vimwebworks.com`.

## Honest limitations (important)

- **The consultation form does NOT send email.** It is a private preview. On submit it shows a
  "Preview only — your request was not sent" notice. Real, secure email delivery is a **separate
  step** to be set up and tested before launch. No personal data is transmitted or stored.
- Sample projects (**Northline Home Services**, **Field & Form Studio**) are clearly-labeled
  **fictional concept work** — not real clients. No testimonials, logos, stats, or results are real.
- `robots` is set to `noindex` while this is a private preview. Remove that before public launch.
- Privacy and Terms are **placeholders** pending review — not real legal text.

## To edit the site

Open `index.html`. All copy, prices, package details, the contact email, and the two sample
concepts live in that one file. Change the text, save, and refresh the browser.

## Moving to Hostinger later

Because this is a plain static site, moving hosts means: upload `index.html` (and any assets) to
the host, then point the domain. Nothing needs to be rebuilt.
